Updated the examples in the documentation to use the built-in CSS support of webpack (i.e. the `css/auto` module type and `experiments.css`) instead of chaining the loader with `css-loader` and `style-loader`. Chaining with `css-loader` and `style-loader` is still supported and documented in the "Using `css-loader` and `style-loader`" section.
